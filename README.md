# Emilia Bravo Portfolio

Editorial portfolio for Emilia Bravo, a full-stack and data engineer building human-centered software, public-health analytics, and civic technology.

## Links

- GitHub repository: https://github.com/emiibra/emilia-bravo-portfolio

## Development

```bash
npm install
npm run dev
```

Open http://localhost:5173/.

## Validation

```bash
npm run check
npm test
npm run build
```

The CS Projects page pulls public repositories live from the GitHub API and keeps featured project recognition cards collapsed until opened.
